# Śląska Kuźnia Młodych Przedsiębiorców

Strona wydarzenia **Śląska Kuźnia Młodych Przedsiębiorców**.

- Strona docelowa: [kuzniamlodych.pl](https://kuzniamlodych.pl/)
- Publiczny podgląd statyczny: GitHub Pages

## Formularz rejestracyjny

GitHub Pages publikuje wyłącznie statyczną część strony. Obsługa formularza znajduje się w `api/register.php` i wymaga hostingu z PHP oraz skonfigurowaną wysyłką poczty.
